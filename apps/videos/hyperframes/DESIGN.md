# Visual Identity: QuickCalAI

## Style Prompt
Clean, modern, and tech-focused with a "dark mode" aesthetic. Professional yet accessible. Focus on precision and AI intelligence.

## Colors
- **Primary:** oklch(0.58 0.22 25) (Cinnabar/Red) - Action buttons, highlights.
- **Background:** oklch(0.09 0 0) (Rich Black) - Canvas.
- **Foreground:** oklch(0.95 0 0) (Off-white) - Main text.
- **Card:** oklch(0.13 0 0) (Dark Gray) - UI elements.
- **Accent:** oklch(0.58 0.22 25) - Accents.

## Typography
- **Headlines:** Plus Jakarta Sans (Extra Bold)
- **Body:** Plus Jakarta Sans (Medium)
- **Accents:** Instrument Serif (Italic) for emphasis if needed.

## What NOT to Do
- Avoid bright/saturated colors other than the primary red.
- Do not use generic fonts like Arial or Roboto.
- Avoid cluttered layouts; keep it minimal and centered.
- No cheesy stock photos; use clean UI mockups or screenshots.
